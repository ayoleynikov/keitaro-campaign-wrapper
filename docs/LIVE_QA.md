## Локальные пути редактора (через наше приложение)

На единственном видимом оффере, только workspace fallback-потока этой кампании:

- Fetch Streams
- Pin текущего share (локально; upstream GET без изменений)
- Cancel (без upstream-мутаций)
- Remove (локальный архив) / Restore
- Reload workspace после Remove сохраняет `removed` + `dirty`
- повторный Cancel → `clean`
- Add того же оффера → 422

Итоговый upstream: кампания disabled, два потока, привязка единственного оффера с share 100 без изменений.

## Stop conditions

1. HTTP **401/403/429** или сетевой блок — остановиться, ключ не подбирать.
2. Любая ошибка write к Keitaro — не повторять мутацию вслепую, не компенсировать DELETE.
3. Не создавать вторую кампанию и не трогать объекты вне allowlist-имени.
4. Не вызывать undocumented routes, не нести cookie, не ходить off-origin с `Api-Key`.
